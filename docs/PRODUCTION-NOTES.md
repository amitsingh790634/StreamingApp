# What I would change for a production cluster

I would move the stack into dedicated namespaces (`streamingapp-prod`, `streamingapp-staging`) with ResourceQuotas and NetworkPolicies so services only talk to Mongo and to Ingress. Secrets would leave Helm values entirely — AWS Secrets Manager or External Secrets, plus a cert-manager Certificate so Ingress is HTTPS-only. MongoDB would become Amazon DocumentDB or Atlas with authentication, backups, and a non-root user; the in-cluster StatefulSet is only a lab default. Every Deployment would keep `maxUnavailable: 0` but I would add an HPA (already sketched in `values-eks.yaml`) and a PDB so a node drain cannot take the last replica. Images would be pinned by digest from a private ECR, scanned on push, and pulled through an IRSA role instead of long-lived access keys. Finally I would split chat onto a sticky Ingress/session affinity layer and put CloudFront in front of S3 so playback never hits the Node.js process.
